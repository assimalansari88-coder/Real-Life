# Real-Life — الحياة الواقعية 🌍

لعبة محاكاة حياة باللغة العربية تعمل مباشرة في المتصفح. عِش حياة كاملة من الولادة حتى الشيخوخة.

## طريقة التشغيل
افتح ملف `index.html` في أي متصفح، ولا تحتاج إلى تثبيت أي شيء.

## طريقة اللعب
- لديك **طاقة ⚡** محدودة كل سنة تصرفها على الأنشطة، ثم اضغط **السنة التالية**.
- **الإحصائيات:** الصحة، السعادة، الذكاء، المظهر، اللياقة.
- **التعليم:** ابتدائي ← ثانوي ← جامعة ← ماجستير ← دكتوراه.
- **العمل:** 13 وظيفة لكل منها شروط تعليم وذكاء، مع ترقيات وطرد وتقاعد.
- **العلاقات:** أصدقاء، شريك، زواج، أطفال، والعلاقة مع الوالدين.
- **التسوق:** سيارات وعقارات وسفر واستثمار.
- **المخاطر:** سرقة وقمار وتدخين، وقد تنتهي بالسجن.
- **أحداث عشوائية وقرارات أخلاقية** تغيّر مسار حياتك.
- عند الوفاة تحصل على **نقاط** حسب إنجازاتك، ويُحفظ أفضل رقم.

يتم حفظ التقدم تلقائياً في المتصفح.
