# شوق — مساعدك الذكي

تطبيق محادثة ذكاء اصطناعي باللغة العربية، بواجهة عربية متجاوبة، ومحادثات محفوظة على جهاز المستخدم، وردود مباشرة أثناء توليدها. يستخدم التطبيق واجهة Anthropic Messages API من الخادم؛ مفتاح المزود لا يصل إلى المتصفح.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

1. انسخ `.env.example` إلى `.env` وضع مفتاح Anthropic في `ANTHROPIC_API_KEY`.
2. شغّل `npm start`.
3. افتح `http://localhost:3000`.

لا يحتاج المشروع إلى مكتبات خارجية. لا تضع مفتاح API في ملفات الواجهة أو في GitHub.

## النشر على Render

أنشئ خدمة جديدة من هذا المستودع باستخدام Blueprint، ثم أدخل `ANTHROPIC_API_KEY` في إعدادات الخدمة. يقرأ Render إعدادات `render.yaml` ويشغّل `node server.mjs`. افحص `/health`؛ تظهر `aiReady: true` عندما يكون المفتاح مضبوطًا.

## الخصائص الحالية

- محادثات متعددة، وإنشاء محادثة جديدة، وحذف محادثة أو كل المحادثات.
- حفظ سجل المحادثات محليًا في المتصفح.
- بث الردود مباشرة، وإيقاف التوليد، ونسخ الرد.
- تصميم عربي RTL متجاوب وقابل للتثبيت كتطبيق PWA.
- حد أقصى لحجم الرسائل والمحادثة، وحد مبدئي 10 طلبات في الدقيقة و60 طلبًا يوميًا لكل عنوان IP، و500 طلب يوميًا للتطبيق كله.

## إعداد الذكاء الاصطناعي

يستخدم الخادم النموذج المحدد في `ANTHROPIC_MODEL`، والافتراضي `claude-haiku-4-5-20251001`. يمكن تغييره من إعدادات البيئة. مفتاح API مطلوب لتوليد الردود، وقد تُحتسب تكلفة الاستخدام على حساب مزوّد النموذج.

## نقاط تشغيلية

سجل المحادثات يبقى على جهاز المستخدم ولا يُرسل إلى قاعدة بيانات التطبيق. يرسل الخادم سياق المحادثة إلى Anthropic لتوليد الرد. عدادات الاستخدام في الذاكرة وتُصفّر عند إعادة تشغيل الخدمة؛ الحدود اليومية تقلل إساءة الاستخدام لكنها ليست حصة فوترة مضمونة. أضف تخزينًا مشتركًا وحدودًا على مستوى الحساب قبل فتح الخدمة على نطاق واسع.
